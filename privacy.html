Kebijakan Privasi

DeisPaint · Terakhir diperbarui: 11 November 2026

DeisPaint adalah editor animasi 2D yang berjalan di browser dan sebagai aplikasi. Halaman ini menjelaskan data apa yang dipakai aplikasi dan untuk apa. Kami berusaha mengumpulkan data sesedikit mungkin.

1. Data yang disimpan di perangkat kamu

Project animasi, gambar, audio, dan pengaturan kamu disimpan di dalam perangkat kamu sendiri (penyimpanan browser/IndexedDB). Data ini tidak dikirim ke server kami selama kamu tidak memakai fitur berbagi. Jika kamu menghapus data browser, menghapus aplikasi, atau berganti perangkat tanpa backup, project bisa hilang. Gunakan fitur backup di aplikasi untuk menyimpan salinan.

2. Fitur Demo / Bagikan (opsional)

Jika kamu masuk (login) dan membagikan project ke tab Demo, data berikut dikirim dan disimpan di layanan Supabase:

  • Email akun yang kamu gunakan untuk login.
  • Data project yang kamu bagikan, termasuk gambar pratinjau (thumbnail).

Project yang dibagikan bisa dilihat oleh pengguna lain di tab Demo. Jangan membagikan project yang berisi informasi pribadi. Kamu bisa menghapus project demo milikmu lewat aplikasi.

3. Layanan pihak ketiga

  • Supabase: untuk login dan penyimpanan fitur Demo.
  • Google Fonts: untuk memuat huruf. Google dapat menerima alamat IP perangkat kamu saat huruf dimuat.
  • Iklan: aplikasi ini mungkin menampilkan iklan di masa depan, misalnya lewat Google AdSense atau AdMob. Jika iklan dipasang, penyedia iklan dapat memakai cookie atau pengenal perangkat untuk menampilkan iklan, termasuk iklan yang dipersonalisasi. Kamu dapat mengatur preferensi iklan Google di adssettings.google.com.

4. Data yang tidak kami kumpulkan

Kami tidak menjual data kamu, tidak meminta lokasi, kontak, atau akses kamera, dan tidak memakai alat analitik pelacak pengguna saat ini. Jika hal ini berubah, halaman ini akan diperbarui.

5. Cookie dan penyimpanan lokal

Aplikasi memakai penyimpanan lokal dan cache (termasuk service worker) agar bisa dibuka lebih cepat dan bekerja tanpa internet. Penyedia iklan atau layanan login juga dapat menyimpan cookie atau token sesi.

6. Anak-anak

Aplikasi ini tidak ditujukan khusus untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data pribadi dari mereka. Jika kamu orang tua dan menemukan data anakmu di fitur Demo, hubungi kami agar dihapus.

7. Hak kamu

Kamu bisa meminta penghapusan akun dan data demo milikmu dengan menghubungi kami di alamat email di bawah. Data di perangkat bisa kamu hapus sendiri kapan saja lewat pengaturan browser atau dengan menghapus aplikasi.

8. Perubahan kebijakan

Kebijakan ini bisa diperbarui sewaktu-waktu. Tanggal pembaruan terakhir tertera di bagian atas halaman.
